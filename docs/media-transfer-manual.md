# 管理员手动转存

入口：**系统设置 → 运维 → 媒体转存 → 转存监控**。

处于「失败」或「等待重试」状态的任务，可以点击「手动转存」：

1. 选择「上传本地视频」或「下载链接」。
2. 上传已生成的 MP4/WebM 文件（最大 200 MB），或填写服务器可直接下载的 HTTP/HTTPS 链接。
3. 选择已启用且已保存的存储渠道，点击「开始转存」。
4. 在转存监控中查看结果。存储后的链接验证成功，原任务会恢复为成功状态。

需要网站登录的预览或下载地址，建议先由管理员下载视频，再使用本地文件上传方式。备用链接经过原有的 SSRF 和重定向校验；原上游的鉴权头不会用于这个新链接。

手动转存沿用原任务与现有结算状态，不提交新的模型生成请求。处理中或已完成的转存任务不能被手动覆盖。

后台接口：`POST /api/option/media_storage/transfers/:id/manual`，使用已有的 RootAuth 权限。Multipart 字段为 `provider_id`，以及互斥的 `file` / `source_url`。任务输入更新和状态变更使用数据库事务与状态比较更新，支持 SQLite、MySQL、PostgreSQL。

手动上传的视频临时文件需要保留在 `MEDIA_SPOOL_DIR`（默认 `/data/media-spool`）中，直至上传完成。部署应挂载持久化目录；若文件在重启后丢失，管理员需要重新上传。
