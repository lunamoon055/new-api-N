# 渠道模型能力同步

渠道能力同步用于补齐文档、模型详情和公开 API 的模型参数元数据。当前支持 V6K（60）、纵横（59），以及 OpenAI／Sora 类型且地址主机精确为 `suanliai.top` 或 `api.meaicc.com` 的渠道，沿用已有适配器实现的公共视频接口。它不提交生成任务，也不修改模型映射、价格或上游请求校验规则。

- 新增或保存支持的渠道后，后台异步刷新，不阻塞渠道保存。
- 主节点启动后刷新已启用的支持渠道，默认每 30 分钟再次刷新。环境变量 `CHANNEL_CAPABILITY_SYNC_INTERVAL_MINUTES` 设置周期，设置为 `0` 可停用启动／定时刷新；保存渠道和手动刷新仍可用。
- 管理员在渠道行的“更多”菜单选择“刷新模型能力”，或调用 `POST /api/channel/:id/capabilities/refresh`。结果包含同步数量和仍有未确认参数的公开模型名称。
- V6K 从渠道地址的公开 `/api/pricing` 读取精确模型 ID 的视频目录；请求不携带渠道密钥。仅解析明确的“30图10音10视”、秒数范围／固定时长／离散秒数和分辨率记法。未提及参考视频不等于明确不支持。
- 纵横从已实现的 `/v1/models?include_capabilities=1` 读取能力。缺失的参考限制保持未知，显式 `0` 保持不支持。多密钥渠道仅在启用密钥的能力一致时发布具体限制。
- 算力 AI 从公开 `/api/pricing` 读取精确 ID，并按照其 `/docs` 公布的规则解析模型名中的明确能力标注；不把目录误标的通用 `openai` 当作视频能力依据。`30-10-10`、`9-3-3` 等末两项相同的已知记法可提取数量；含义不明确的其他三元组保持未确认。
- CC API 从公开 `/api/pricing` 的模型备注提取能力，包括 `4-30s`、`30图10视频10音频`、分辨率和明确的比例范围。公开目录不发送渠道密钥；对这些公开站点使用普通 HTTP User-Agent 以兼容目录读取。

结果持久化在 `channel_model_capabilities`。范围摘要包含渠道类型、地址、凭证、代理和密钥启用状态，表内不保存明文凭证。文档只发布当前渠道范围与最终映射模型匹配的限制；同一公开模型换映射时可继承已确认的 `/v1/videos` 字段模板，但旧时长、分辨率和素材上限会清空为未确认。已识别的文本／图片模型及专用端点不会继承视频模板。上游读取失败时保留同一范围内最后成功的数据及更新时间，读取成功但找不到目标模型时记录未知能力。

`/api/pricing` 和 `/v1/pricing` 共用 `mapped_endpoints`。`parameters` 保留适配器字段，`documentation_fields` 使用已支持的公共别名（`duration`、`ratio`、`resolution`、`referenceImages`、`referenceVideos`、`referenceAudios`）。能力对象通过 `unknown_fields` 区分部分未公布项目，通过 `capabilities_unknown` 表示整体未知；显式零与未知不能互换。相同公共模型跨渠道出现不同能力时显示未确认，避免只展示其中一个渠道的限制。

接入文档保持原有刷新习惯：打开时读取一次，其后由用户点刷新／重试读取当前目录；服务端的定时同步不触发浏览器轮询。显示和复制文档都保留未确认、不支持的参数行。比例范围未公布时继续遵循站点已配置的完整比例菜单。

这份元数据不是付费生成验收结果；供应商备注无法解析的内容保留未确认，不使用模型名称猜测能力，也不覆盖管理员维护的模型介绍或端点配置。
