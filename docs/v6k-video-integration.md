来源：[统一视频文档](https://www.v6k.top/docs?guide=unified&category=video)、公开 `/api/pricing` 和 `/api/status`。原始快照核对日期为 2026-10-24，新增 11 个模型于 2026-10-26 复核。

## 渠道与模型

渠道类型 `V6K`（60），地址 `https://www.v6k.top`，支持视频创建、任务查询和内容下载。视频接口不支持 StreamOptions。后台“获取模型”使用密钥授权的 `/v1/models` 与公开目录的 `openai-video` 分类取交集，不把文本、图像或音乐模型导入视频渠道。

本地 ZH 渠道（5）最初配置 27 个视频模型，新增 11 个后共 38 个；本轮不删除旧模型。两个与已有渠道重名的模型采用 `V6K/` 公共别名；渠道映射到原始上游 ID。其余模型使用原始 ID。不要将这两个别名直接提交到上游。

## 下游调用

使用本站 API Key。提交后取本站任务 ID，再查询并下载：

```http
POST /v1/videos
Authorization: Bearer <本站 API Key>
Content-Type: application/json

{"model":"dola2.0","prompt":"镜头缓慢推进，一片阳光下的森林","seconds":15,"resolution":"720p"}
```

- `GET /v1/videos/{本站任务ID}`：查询任务状态。
- `GET /v1/videos/{本站任务ID}/content`：内容下载；支持 Range、If-Range 和 206。
- `HEAD /v1/videos/{本站任务ID}/content`：内容头信息。
- `GET /v1/models`：读取模型及支持的端点类型。
- `GET /v1/pricing?currency=CNY`：读取令牌授权范围内所有模型的价格、单位和 mapped_endpoints 参数提示，使用 price_configured 区分未配置与免费。

JSON 支持 `seconds`、`ratio`、`resolution`、`size`、`images`、`videos`、`audios`、`input_reference` 和 `metadata`。参考素材可为公共 HTTP(S) URL，视频/音频也可带 `duration_seconds`。本地文件通过 multipart 上传，不能将本地路径或 data URL 当作上游可访问地址。首帧 input_reference 与参考图数组分开传递。ratio/resolution/size 同时出现必须一致。元数据保留显式 false/0，但不得覆盖模型和计费字段。按秒模型必须明确传 seconds，避免未传时长而按上游默认时长生成。

模型参数提示仅来自公开描述。dola2.0 固定 15 秒；未公布时长范围的模型提供手动时长输入，具体支持范围由上游校验，不沿用同名旧渠道的默认值。

## 异步与验证边界

提交只接受一次上游 POST。网络中断、重定向或错误返回后不自动跨渠道重发，避免同一请求创建多个付费任务。上游未文档化幂等键，因此不会发送虚构的幂等头。

正常轮询间隔 20 秒；网络错误、无效响应和 429 等暂时错误至少退避 40 秒，并遵守更长的 Retry-After。unknown 保持待处理，只有明确 failed 才进入失败退款流程。completed 即使没有 URL 也通过固定 content 接口下载。上游任务 ID 和提交时密钥保存在任务私有数据，内容鉴权只发给同源地址。

验证包含上游真实授权模型读取、本地配置和价格读取、模拟提交/查询/下载/退款状态测试，以及前端类型检查和构建。尚未发起上游真实付费视频生成；模拟生命周期通过不代表上游实际生成成功。
