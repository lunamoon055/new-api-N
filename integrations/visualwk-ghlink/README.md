# GHLINK 视频与图片 · 视觉工坊插件 v1.3.3

连接 `https://ghlink.top`，供 `https://unline.visualwk.com` 的「节点插件」使用。
参考用户提供的 V6K / 字字动画插件的业务流程，重新实现为浏览器 ESM 插件；不运行或改写原 Python 插件。

## 安装和使用

1. 进入视觉工坊画布，左上角菜单 → **节点插件 → 第三方插件**。
2. 将交付包 `安装链接.txt` 的全部内容复制到链接框，点击 **安装**。这是包含插件源码的自包含链接，不含 API Key，也无需临时服务器。
3. 底部 **扩展节点 → GHLINK 视频 / 图片**，添加节点。旧版已有节点可直接继续使用。
4. 填写 GH API Key，点击 **连接并刷新模型**。选择生成类型和模型，填写提示词与参数，再点击 **生成视频 / 生成图片**。
5. 已有任务可粘贴 GH 返回的任务 ID，点击 **继续查询**。这一步不会创建新任务。

### 从 v1.0.0 / v1.1.0 / v1.2.0 / v1.3.0 / v1.3.1 / v1.3.2 升级

在「第三方插件」链接框中粘贴本版本 `安装链接.txt` 的全部内容，再点击 **安装**，会覆盖同 ID 的旧插件，无需卸载或删除画布节点。旧版自包含链接不会自动变为新版本，请勿只点旧记录的「从来源更新」。更新后刷新其他已打开的画布标签页，重新填写 Key 并刷新模型。

### v1.3.3 操作按钮与结果预览

生成图片/视频改为蓝色主按钮，新任务、选中结果节点及查询操作改为描边按钮。操作区按钮最小高度 36px，圆角 8px，间距 8px，宽度不足时自动换行。支持悬停、键盘焦点及灰色禁用状态，并使用宿主主题色适配浅色和深色界面。沿用 v1.3.2 的任务提交和恢复逻辑。

图片生成不再显示「图片调用方式」或协议说明。选择模型、提示词及参考素材后直接生成，由插件根据已支持的模型目录构建图片请求。取消 sunburst 默认选项的特殊拦截；默认请求与用户已确认可成功的「图片接口 · URL 参考图」选项完全一致。旧节点保存的接口选择不再参与提交，其他图片模型继续使用原有字段与参数。失败后不会自动换接口或补发请求。「生成信息」只显示模型与参考素材数量。

参考 infinite-canvas_副本 的站内图片详情交互，结果节点展示缩略图、实际尺寸、完成状态，以及独立的「查看大图」「下载图片」按钮。点击缩略图也能预览；站内弹层支持放大、缩小、适应窗口、原始尺寸、滚动查看细节、Esc 关闭和焦点返回。弹层使用浏览器顶层对话框，避免被画布变换和节点边界裁切，不依赖宿主未开放的图片预览接口。

下载先读取原文件，再通过 Blob 保存到本地；不使用外链跳转，也不向媒体服务发送 GH Key。视频使用同一下载流程。下载失败时在站内提示，可重试下载，不重复生成。远程媒体必须允许跨域读取，禁止读取时无法由插件绕过；已核对现有 media.ghlink.top 图片返回跨域允许头。

49 项测试通过；包含 sunburst 默认请求与原 URL 选项的一致性，以及 sunburst/flare/gpt-image-2 × 三种旧接口设置的 9 组实际生成处理器检查，确认参考图与 @ 编号保留、只提交一次且无接口选择控件。独立浏览器模拟页验证 sunburst 与 flare 都能直接提交并接收原结果，没有真实生成费用。

浏览器另已验证浅色/深色、画布缩放、站内预览、关闭返回、原始尺寸与放大操作，并用本地 PNG 及 GH 已有公网图片验证直接下载。文件分别确认为 1536×1024、1254×1254 的 PNG；模拟下载失败后可恢复重试，页面 URL 始终停留在站内验收页。没有创建真实生成任务或产生生成费用。

按用户本轮明确授权，已生成 v1.3.3 安装包，并在当前 Edge 的在线视觉工坊覆盖安装。插件管理器显示 v1.3.3，原有画布节点、连线和结果保留。在线复核接口选择控件及旧外链均已消失，4 个已有图片结果显示站内预览/下载按钮；已有图片的站内预览与实际下载通过，保存文件确认为 1312×1199 PNG。Edge 当前设置会要求点击「保存」，已完成本次验收文件的保存，没有更改浏览器下载设置。更新后需重填内存 Key 并刷新模型目录；历史失败结果保留原记录，新请求按新版流程执行。本轮未新增真实生成请求或费用。

### v1.3.2 创建任务时中断修复

旧版在节点组件卸载时调用 AbortController.abort()。创建结果节点触发画布重建、节点临时离开可视区域等情况下，视图卸载会直接中止正在提交的图片请求或视频查询；重新挂载后还会丢失模型列表和忙碌状态。

- 将每个节点的任务控制器、提交锁、模型目录、内存 Key、状态消息和结果节点编号保存在插件实例中。组件卸载只解除界面订阅；重新挂载会继续显示同一任务，原响应写回原结果节点。
- 创建结果节点前即取得共享提交锁，节点重建后仍禁止重复点击发起新请求。手动停止操作会找到原控制器，响应不确定时继续保留待核对状态。
- 任务在原节点被删除、插件被卸载或用户主动停止时结束本页等待。视频任务 ID 继续保存；停止等待不取消上游任务。
- 生成过程中注册浏览器离开提醒，完成后移除，以减少误刷新导致的响应丢失。是否显示由浏览器决定。**强制刷新、关闭页面或浏览器崩溃仍会终止页面内请求**；已有视频任务可重填 Key 后继续查询，同步图片响应丢失则需先核对 GH 记录，不能自动重新提交。

本节记录任务生命周期修复。旧的 sunburst 参考图排查及临时接口选择见下节；当前源码的简化提交行为见 v1.3.3。

### v1.3.1 图片参考协议候选修复（历史记录，当前界面已移除接口选择）

当时增加了显式选择接口的临时诊断入口。用户后续反馈默认选项会被拦截，而显式 URL 参考图选项能成功；v1.3.3 已移除这条默认拦截和界面选择。以下仅记录历史实现，不是当前使用步骤。

- 「图片调用方式」新增显式的多模态对话模式，仅在 GH 模型目录声明 `/v1/chat/completions` 或 `openai` 端点时可选。参考图作为 `messages[].content[].image_url` 发送到对话端点，绝不把 `messages` 拼在图片生成端点上。
- 对话模式发送 `model`、`messages`、`stream:false`。每张图前附 `@图N` 标签，比例和分辨率放在文本中表达，不强行发送图片接口参数；是否遵循仍由模型决定。
- 接受对话返回的图片内容和 Markdown 图片。仅返回文字、普通链接或原参考图时明确报错，不伪装成新图生成成功。
- 已有受控诊断显示 `gpt-image-2.5-sunburst` 在图片接口使用 `images` 或 `messages` 均未保留参考内容。因此该精确模型在带参考图且未明确选择接口时会先提示，不会上传或发出付费请求。可明确选择旧图片接口或待验证的对话接口；其他模型及纯文生图保持原行为。
- 「本次请求核对」显示实际提交端点、模型和各类素材数量，不保存 Key、请求正文或素材公网链接；它只能证明插件构建了什么，不能证明上游最终采用了参考图。
- 每次点击只提交一次；失败、超时或没有图片均不会切换接口补发。

上游公开文档当前只有最小图片生成示例；模型详情列出图片与对话端点，但未说明该型号参考图的成功契约。尚无依据默认改成 `/images/edits` 或声称某种字段必然有效。详见 `REFERENCE-DIAGNOSIS.md`。

### 使用 @ 引用素材

1. 将图片、视频、音频节点连入插件左侧接口。
2. 在提示词输入 `@`，弹出已连接素材列表。继续输入文件名或素材类型可筛选，例如 `@28` 可以找到 `28.mp3`。
3. 点击素材，或按上下方向键选择、回车插入。按 Esc 关闭列表；Shift + Enter 仍可换行。
4. 例如：`让 @图片1 中的人物进入 @图片2 的场景，动作参考 @视频1，背景音乐参考 @音频1`。输入框下方显示引用标签与文件名。

菜单插入的引用绑定具体节点，名称相同的素材也能区分。连线顺序改变时保持绑定，提交时按最终去重后的素材数组重新映射；断开已引用素材会显示“已断开”，并在上传和提交前阻止生成。删除提示词中不再需要的引用即可解除该引用要求。

图片提交使用接口文档规定的 `@图N` 标记。视频和音频引用会附加简短的顺序对应说明，不增加未声明的 API 字段；实际参考效果仍取决于所选模型的能力。手动粘贴、未经菜单绑定的编号只按当前素材数组顺序解释，并校验编号是否存在。

连线素材仍会一起提交，`@` 用于说明各素材在提示词中的用途，不表示只上传被提及的素材。菜单仅列出直接连接的图片、视频、音频；文本节点继续作为提示词为空时的文本来源。

### 连接素材与画布结果节点

- 把图片、视频、音频或文本节点的输出连入插件左侧接口。「已连接素材」会显示类型、顺序与文件名，增删连线会更新列表。只读取直接连入的节点，不扫描无关节点或反向输出连线。
- 点击生成时重新读取最新连接快照。优先使用公共链接；本地 Blob 和已过期的 Blob URL 通过节点的 `storageKey` 从画布现有 IndexedDB 媒体库读取。需要上传的文件通过视觉工坊配置的同源媒体入口 `/api/media/upload` 转为公共链接，不向该上传入口发送 GH Key。
- 已连接素材和手填链接一起去重、校验，图片节点使用当前主图。素材缺失或超过模型上限会明确报错，不能读取的素材不会被静默忽略。文本连接只在插件提示词为空时作为提示词使用。
- 点击生成会在插件右侧创建独立的图片或视频结果节点，并自动连线。节点可以拖动、缩放、继续连接下游，生成过程不显示页面弹窗或遮罩。
- 结果节点内展示准备、排队、生成、完成或失败状态，完成后在同一节点显示预览。只有接口返回真实百分比时才显示百分比，否则使用不定进度条和等待时间。
- 新任务会保留旧结果，下次生成创建新节点并避让已有节点。继续查询会复用当前结果节点，不重新提交任务。升级前已有的视频任务，也可凭任务 ID 继续查询并创建结果节点。
- 节点组件在同一页面内重新挂载后，任务继续等待并接收结果。删除节点或停止本页等待不会取消上游任务。整页刷新后须在原插件节点重填 Key，已有视频任务可继续查询；页面关闭时不会自动在后台轮询。

插件安装和画布按视觉工坊现有机制保存在当前浏览器中；其他浏览器需分别安装。安装不等于向全站发布官方插件。

`ghlink-video.mjs` 本身就是可安装的 ESM，不需要编译。批量分发时可将其原样托管为 `ghlink-video.js`，使用允许视觉工坊跨域读取的 HTTPS 静态链接安装。覆盖同一托管 URL 后，在插件管理器点击「从来源更新」。自包含安装链接固定对应当前版本，新版本需要用新的安装链接再次安装同 ID 插件。

## 支持范围

- 使用 Bearer Key 请求 `/v1/models` 与 `/v1/pricing?currency=CNY`，取授权模型交集，支持映射到 `/v1/videos` 的视频模型和 `/v1/images/generations` 的同步图片模型。
- 使用接口公布的 `mapped_endpoints[].parameters` 映射时长、比例、分辨率、图片/视频/音频 URL 字段和素材上限；未公布的范围显示手动输入，不猜测模型能力。
- 参考素材支持连入节点中的本地图片、视频和音频，也支持手填公共 HTTP(S) 链接，每行一个。当前没有首尾帧专用控件或文本生成模型入口。
- 图片生成支持 URL 或 Base64 返回，参考图按目录声明的 `image_field` 提交，用户无需选择接口。尚不支持 `/images/edits`、仅有对话端点的图片模型或专有异步图片协议，不会自动猜测协议或丢弃参考素材继续生成。
- 读取并标注按次/按秒基础价，区分免费和未配置价格；不将基础价当作最终费用，不执行动态计费表达式。
- 提交仅发送一次 POST；失败或响应丢失时保存“待核对”状态，不自动再次创建任务。查询通常间隔 20 秒，暂时失败退避至少 40 秒并遵守 Retry-After。
- 保留任务 ID，支持刷新后重新填写 Key 继续查询。停止本页查询不会取消 GH 任务或承诺退款。
- 完成后在结果节点显示预览和站内下载按钮。图片可在站内放大查看。认证视频内容以 Blob 保存至宿主提供的插件私有存储，节点保存其存储键，播放时创建临时 URL；本地存储不会自动跨浏览器同步。图片 Base64 和公共结果链接随画布保存，结果节点可作为后续插件的输入。公共链接有效期由 GH 决定。

## 凭据和数据

API Key 只保留在插件实例的页面内存中，节点组件重建会保留各节点当前 Key，整页刷新需重填；不进入节点元数据、安装链接或交付包。认证请求固定发送到 `https://ghlink.top`，禁止自动重定向，不向外部视频主机附带 Key。

提示词、模型选择、参考链接、任务 ID 和生成结果随画布保存在当前浏览器中。点击生成后，连接的本地素材可能上传至视觉工坊已配置的媒体服务；生成请求及素材链接提交给 GH，真实调用按 GH 规则计费。插件与其他视觉工坊节点插件一样在页面主环境运行，并非安全沙箱。
